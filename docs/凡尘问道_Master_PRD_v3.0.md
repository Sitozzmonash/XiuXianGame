> 文档定位：完整产品需求文档 / 游戏设计总纲 / 开发 Agent 单一事实源（Single Source of Truth）  
> 项目类型：竖屏 H5 / Web 多端适配 · 修仙题材 · 自动战斗 · 挂机养成 · 爆装刷宝 · Build 构筑 · 剧情奇遇 · 秘境探索  
> 开发方式：AI Agent 驱动开发，优先在现有项目上增量实现，不推翻已有可用代码  
> 美术方向：国风水墨 + 半写实修仙 + 手绘 UI + 冷色灵力特效  
> 核心关键词：自动推关、爆装备、5+2 法宝、Build、境界突破、24h 挂机、剧情、奇遇、秘境、因果、长线 NPC、修仙人生

# 0. 文档使用规则

1. 本文档是开发 Agent 的最高产品规则；如果旧 PRD 与本文冲突，以本文为准。
2. 已经在现有项目中稳定运行的功能，原则上保留并增量升级，不为了“代码整洁”重写。
3. 游戏第一核心是“好玩”，不是“系统数量多”。任何新增系统必须至少强化：战斗爽感、爆装、Build、剧情/奇遇、修仙沉浸中的一项。
4. 所有内容尽量配置化，禁止把大量关卡、剧情、法宝、装备、NPC 逻辑硬编码在 UI。
5. 先做一个完整、连贯、可玩 30~60 分钟的前期闭环，再批量扩充 1000 关内容。
6. 剧情必须短而有用：推进人物、揭示世界、触发选择、奖励 Build 或形成因果。禁止大段无意义文字灌输。
7. 自动战斗不等于没有玩法；玩家的主要玩法是“选择、构筑、风险决策、资源分配、路线判断”。
8. 首版不做强制广告、不做充值、不做 PvP、不做实时多人。

# 1. 产品愿景

《凡尘问道》是一款让玩家从普通凡人出发，在水墨修仙世界中自动斩妖、爆装、组合五件主动法宝与两件被动法宝、研究不同 Build，同时经历奇遇、秘境、宗门、因果与人物故事，一路从炼气修到飞升的竖屏修仙游戏。

玩家不应该只记得：

> “我打到了第 327 关。”

更希望玩家记得：

> “我炼气期在黑风岭救过沈青禾，后来因为一卷残缺剑诀与宗门长老结怨；结丹后在无尽海重新遇见她，我们一起进入古舟秘境，我最终走成了自己的剑阵流。”

游戏最终需要同时满足四种驱动力：

- **即时驱动**：战斗特效、爆装、数字上涨。
- **构筑驱动**：装备、法宝、功法、灵根、灵兽之间形成真正联动。
- **叙事驱动**：玩家想知道下一段剧情、NPC 命运与飞升真相。
- **长期驱动**：境界、收藏、洞府、宗门、秘境与排行榜。

# 2. 目标用户与体验节奏

## 2.1 目标用户

- 喜欢修仙、仙侠、凡人流题材。
- 喜欢挂机成长，但不希望只是纯数值放置。
- 喜欢爆装备、词条筛选、Build 构筑。
- 喜欢剧情奇遇，但不希望每次登录都要读大量文字。
- 单次游玩 3~20 分钟，偶尔连续玩 30~60 分钟。

## 2.2 推荐节奏

一次普通登录：

```text
领取挂机收益 30~60 秒
→ 处理装备 / 法宝 / 功法 1~3 分钟
→ 自动推关 2~10 分钟
→ 遇到剧情 / 奇遇 / Boss
→ 做选择或调整 Build
→ 进入秘境 / 突破 / 宗门活动（可选）
→ 离线
```

剧情节奏：

- 普通剧情节点：20~60 秒。
- 重要剧情节点：1~3 分钟。
- 单个大型秘境：8~20 分钟。
- 每 5~15 分钟应至少出现一次“不是纯打怪”的内容。

# 4. 世界观

世界层级：

```text
凡域
↓
修真界
↓
海外修真域
↓
上古遗境
↓
灵界
↓
仙域
```

数万年前发生过一次被后世称为“断天之劫”的上古灾变。

后世普遍相信：

> 飞升，是所有修士的终点。

但随着玩家逐步成长，会发现一部分上古顶级修士曾主动摧毁飞升通道。

玩家开局获得的“残破古玉”是解开这一秘密的钥匙之一。

世界中的主要势力：

- **青玄剑宗**：正道剑修宗门，重秩序、重传承。
- **五雷山**：雷法宗门，善阵法与雷术。
- **镇岳门**：体修宗门，守护边境与古封印。
- **幽冥谷**：被正道视为魔门，实际内部派系复杂。
- **百草谷**：炼丹、灵植势力。
- **海天楼**：海外商会与情报组织。
- **太虚盟**：跨宗门秩序组织，暗中追查上古飞升遗物。
- **万妖庭**：妖族联盟，掌握部分上古真相。
- **无门散修盟**：松散的散修互助组织。

# 5. 大境界

完整境界：

1. 炼气。
2. 筑基。
3. 结丹。
4. 元婴。
5. 化神。
6. 炼虚。
7. 合体。
8. 大乘。
9. 渡劫。
10. 飞升。

炼气表现：

```text
炼气一层 → ... → 炼气九层 → 炼气圆满
```

其余大境界：

```text
初期 → 中期 → 后期 → 圆满
```

突破条件：

```text
修为达到上限
+
指定突破材料
+
关键剧情 / 突破 Boss / 心魔 / 天劫
```

突破失败原则：

- 不掉境界。
- 不掉装备。
- 修为不清零。
- 部分消耗品可保留。
- 高境界失败可以进入短期“虚弱”状态，但不能形成永久惩罚。

每个大境界突破必须包含：

- 一段剧情。
- 一个关键抉择。
- 一次战斗或考验。
- 一段视觉演出。
- 新内容解锁。
- 明显属性变化。

# 6. 15 章完整主线

以下 15 章是游戏主线骨架。每章至少包含：开场、3~6 个剧情节点、关键奇遇、章节 Boss、关键选择、后续影响。

## 第一章：青石村 · 凡尘起灵（炼气初期）

**主题**：普通人第一次接触修仙世界。  
**主要敌人**：山狼、野猪、山匪、血目猿、低阶妖兽。  
**主要 NPC**：主角养父林伯、少女医者苏晚、巡山人赵石。

剧情：

1. 青石村连续有人失踪，村民认为是野兽袭击。
2. 主角帮助巡山队进入山林，第一次遇到明显超出普通野兽能力的妖兽。
3. 山匪尸体上发现一枚温热古玉，主角收下。
4. 当晚梦见倒悬云海的宫殿，听见：“九劫未尽……此世，又是谁得了它？”
5. 失踪村民被发现困在山神庙地下，山神像内部藏有人工布置的御兽符。
6. Boss **血眼山君** 出现。
7. 击杀后从其体内取得“御兽钉”，确认妖患有人操控。

关键选择：

- 将御兽钉交给村中老人查看：获得人脉线索。
- 自己保留研究：古玉共鸣 +1。
- 交给路过修士：提前引出修真界线索。

章节结尾：

主角确认世界上真的存在修仙者，决定追查御兽钉来源，离开青石村。

解锁：

- 背包。
- 装备。
- 基础战斗。
- 法宝第一槽。
- 仙途录。

---

## 第二章：黑风岭 · 初见仙途（炼气）

**主题**：第一次面对正魔与利益选择。  
**NPC**：沈青禾、黑风道人、散修罗七。

剧情：

1. 玩家在黑风岭发现被追杀的年轻修士 **沈青禾**。
2. 她身中阴煞毒，旁边有三名邪修尸体。
3. 玩家选择救她、搜身或离开。
4. 黑风岭深处出现大量被控制妖兽，与青石村御兽钉同源。
5. 散修罗七告诉玩家：黑风道人最近大量收购凡人魂魄。
6. 玩家潜入邪修洞府，发现黑风道人利用御兽钉与魂幡炼制兽魂。
7. Boss **黑风道人**。

关键选择：

- 杀死黑风道人：道心 +1，青玄剑宗声望 +。
- 接受《残篇·噬魂诀》：魔念 +1，开启魂修路线。
- 废去其修为：黑风道人存活，后续可能回归。

如果沈青禾被救，她会留下玉符：“若有一日到云泽坊市，可凭此找我。”

章节结尾：

玩家从洞府资料中发现“云泽坊市”和“太虚盟”的名字。

解锁：

- 功法。
- 法宝 5 主动槽逐步开放。
- 因果变量系统。

---

## 第三章：云泽坊市 · 修真世界（炼气中期）

**主题**：真正进入修士社会。  
**NPC**：沈青禾、顾长风、百里商、阿梨。  
**核心地点**：坊市、黑市、拍卖行、炼丹铺、散修客栈。

剧情：

1. 玩家首次见识灵石交易、炼丹、炼器、宗门招募。
2. 若救过沈青禾，她帮助玩家取得临时身份；否则需要完成散修任务。
3. 拍卖会上出现第二枚与玩家古玉材质相同的残片。
4. 太虚盟执事 **顾长风** 高价买走残片。
5. 玩家从情报贩子处得知，太虚盟已秘密寻找类似古玉数百年。
6. 一名小女孩 **阿梨** 偷走玩家灵石，追捕后发现她为救病重兄长。
7. 坊市夜间发生劫杀，幕后势力目标不是灵石，而是古玉残片。

关键选择：

- 帮助阿梨：后续开启灵兽/妖族线。
- 抓她交给执法堂：获得资源与坊市声望。
- 买下她的情报：获得黑市入口。

Boss：

**噬金蜈蚣王** / 黑市劫修首领（根据路线）。

章节结尾：

玩家获得筑基材料线索：落霞山脉存在古修洞府与地脉灵髓。

解锁：

- 坊市。
- 炼丹初级。
- 炼器初级。
- 商店刷新。
- 支线任务。

---

## 第四章：落霞山脉 · 古修遗府（炼气后期）

**主题**：机缘与代价。  
**核心秘境**：落霞古洞府。  
**NPC**：沈青禾、剑客谢无尘、古修遗魂。

剧情：

1. 多名炼气圆满修士争夺筑基资源。
2. 玩家发现一座被阵法隐藏的古修洞府。
3. 洞府中存在残破药园、古修尸骨、妖兽巢穴、剑碑。
4. 古修遗书写明：他当年为抢筑基丹杀了同行好友，最终终生无法结丹。
5. 玩家可安葬、搜尸或参悟其禁术。
6. 剑碑与古玉短暂共鸣，出现“断天之劫”的模糊画面。
7. 剑客 **谢无尘** 为抢剑碑与玩家发生冲突，也可根据选择转为合作。

Boss：

**石甲地龙**。

关键选择影响：

- 道心。
- 剑道因果。
- 谢无尘关系。
- 是否获得《无名剑章·上卷》。

章节结尾：

玩家取得部分筑基材料，但最核心的地脉灵髓在赤炎秘境。

---

## 第五章：赤炎秘境 · 筑基之劫（炼气圆满 → 筑基）

**主题**：第一次大规模修士争夺与上古谜团。  
**NPC**：沈青禾、顾长风、谢无尘、黑风道人（若存活）。

剧情：

1. 多方势力进入赤炎秘境争夺地脉灵髓。
2. 太虚盟真正目标是秘境深处的“赤炎古碑”。
3. 玩家发现古碑与自己的古玉产生强烈共鸣。
4. 黑风道人若存活，会尝试夺取古玉。
5. 沈青禾可能为保护玩家受伤，也可能因早期关系保持距离。
6. 古碑开启上古影像：无数修士飞向天穹，却有人惊恐逃离仙门；最终一名修士主动击碎飞升阵。
7. 玩家取得地脉灵髓并开启筑基心魔。

突破 Boss：

**赤炎古灵 + 筑基心魔**。

关键选择：

- 以剑破心魔：攻击型筑基增益。
- 守心渡劫：道心型增益。
- 借古玉镇压：古玉共鸣增加，但太虚盟关注度上升。

解锁：

- 筑基。
- 洞府。
- 完整秘境系统。
- 第二套 Build 方案。

---

## 第六章：苍梧古林 · 妖灵之约（筑基）

**主题**：人族与妖族并非简单善恶。  
**NPC**：阿梨、妖族少年玄羽、百草谷弟子叶清檀。

剧情：

1. 苍梧古林灵药异常枯萎，人族修士怀疑妖族作乱。
2. 玩家追查发现有人抽取古林地脉灵气炼制“化妖丹”。
3. 阿梨真实身份被揭示：她拥有稀薄妖族血脉。
4. 玩家救下被猎杀的妖族少年玄羽。
5. 百草谷与万妖庭因误会即将冲突。
6. 真凶是太虚盟外围势力，通过古林地脉寻找第三枚古玉残片。
7. 玩家可以帮助调停、支持百草谷或帮助妖族反击。

Boss：

**枯木妖王 / 化妖丹傀儡**。

关键后果：

- 妖族声望。
- 百草谷声望。
- 阿梨后续身份。
- 是否获得灵兽“青灵狐”。

解锁：

- 灵兽。
- 灵田。
- 高级炼丹。

## 第七章：万骨荒原 · 白骨旧战（结丹）

**主题**：历史由胜者书写。  
**NPC**：顾长风、幽冥谷弟子洛无衣、亡魂将军。

剧情：

1. 玩家为结丹寻找“阴阳玄髓”进入万骨荒原。
2. 荒原遍布古代修士尸骸，被认为是魔修造成的大屠杀遗址。
3. 玩家遇到幽冥谷弟子 **洛无衣**，其目标是安葬同门亡魂。
4. 古玉让玩家看到遗留记忆：当年的战争并不是正道讨魔，而是太虚盟前身为了争夺飞升遗物发动清洗。
5. 顾长风开始怀疑自己所在组织。
6. 玩家进入白骨城，面对被执念困住的亡魂将军。
7. 可选择净化、超度或利用其魂力。

Boss：

**白骨将军·韩冥**。

突破：

结丹需要决定“丹心”方向：

- 剑心丹。
- 五行丹。
- 金身丹。
- 血魂丹。
- 自在丹。

解锁：

- 结丹。
- Build 核心分支。
- 魔修不再只是隐藏路线，正式成为合法玩法。

## 第八章：无尽海 · 沉舟仙影（结丹）

**主题**：海外修真与消失的航路。  
**NPC**：海天楼少主宁照海、沈青禾、神秘女修“月璃”。

剧情：

1. 海外不断有修士失踪，海天楼悬赏调查。
2. 玩家登上古舟“归墟号”。
3. 古舟实际是一座上古跨界传送器残骸。
4. 舟内时间流速异常，玩家看到不同年代留下的修士影像。
5. 沈青禾寻找失踪师父的线索，发现其可能进入过归墟号。
6. 神秘女修月璃似乎认识玩家古玉，却拒绝说明身份。
7. 玩家在船底发现第四枚古玉残片，但它已被某种“仙纹”污染。

Boss：

**深海蜃龙**。

关键选择：

- 净化残片：古玉稳定。
- 融合污染残片：获得强力效果，增加“仙蚀”变量。
- 交给顾长风研究：太虚盟线深入。

解锁：

- 海外地图。
- 第三套 Build。

## 第十五章：飞升台 · 天门问道（渡劫 → 飞升）

**主题**：玩家最终决定“何为飞升”。  

剧情：

1. 世界各势力汇聚飞升台。
2. 闻天策认为：没有亲眼见过仙域，就不能因上古恐惧永远封门。
3. 守界派认为：天门一旦彻底开启，两界本源都会被吞噬。
4. 玩家用问道界玦进入天门核心。
5. 发现“仙域”不是单纯邪恶世界，而是一个极高层级文明体系；部分仙域势力确实长期抽取下界本源。
6. 上古断天者毁掉通道，是为了阻止某一仙域势力，并非否定所有飞升。
7. 闻天策最终可能成为敌人、盟友或牺牲者。

最终 Boss：

**天门化身“九劫仙影”**。

最终选择：

### 结局 A：封天

永久关闭当前天门。

- 下界安全。
- 玩家留在本界成为守界者。
- 后续可开启“守界纪元”。

### 结局 B：重铸天门

利用问道界玦建立受控的新天门。

- 允许有限跨界。
- 玩家成为两界秩序建立者。
- 推荐默认“真结局”。

### 结局 C：独自飞升

玩家直接穿越天门进入仙域。

- 世界后续由已有 NPC 决定。
- 开启未来仙域篇章。

### 隐藏结局 D：问道无门

需要高道心、关键 NPC 存活、完整断天真相、低仙蚀。

玩家摧毁旧天门后自行创造新的修行道路。

# 7. 8 名贯穿型重要 NPC

## 7.1 沈青禾

定位：最早遇到的真正修士之一。  
性格：冷静、克制、重承诺。  
成长：筑基散修 → 宗门核心 → 元婴修士。  
核心线：寻找失踪师父、调查太虚盟。  
关系结果：挚友 / 道友 / 疏远 / 敌对 / 战死。  
注意：不强制做恋爱系统，可保持纯道友关系。

## 7.2 顾长风

定位：太虚盟年轻执事。  
性格：相信秩序，但愿意质疑组织。  
成长：盟内精英 → 怀疑者 → 叛逃者/改革者。  
核心线：太虚盟真相。  
结局：新盟主 / 牺牲 / 执迷于秩序。

## 7.3 谢无尘

定位：天才剑修，亦敌亦友。  
性格：骄傲、直接、极度重剑道。  
成长：争夺剑碑 → 宗门核心 → 大乘剑修。  
核心线：剑道与宗门责任冲突。  
可解锁：无名剑章完整传承。

## 7.4 阿梨

定位：云泽坊市的小偷少女。  
真实身份：妖族混血。  
成长：凡俗骗子 → 灵兽师 / 妖族使者。  
核心线：身份认同、人妖关系。  
关键：她的存活与选择影响万妖庭剧情。

## 7.5 洛无衣

定位：幽冥谷弟子。  
性格：冷淡、讽刺、但尊重亡者。  
成长：被视为魔修 → 揭示魔道真相。  
核心线：坠魔谷、仙蚀禁术。  
可解锁：魂修高级 Build。

## 7.6 月璃

定位：无尽海出现的神秘女修。  
真实身份：守门人后裔。  
核心线：断天之劫、界门钥。  
特点：知道很多，但因为誓约不能早期直接说明。

## 7.7 玄羽

定位：苍梧古林妖族少年。  
成长：被猎者 → 万妖庭核心人物。  
核心线：人妖盟约。  
如果早期死亡/敌对，后期万妖庭路线显著不同。

## 7.8 闻天策

定位：主要对立人物，但不是纯反派。  
信念：上古修士无权替后世永久决定是否飞升。  
目标：重开天门。  
特点：其逻辑必须有合理性。  
最终可：敌人 / 合作者 / 牺牲者。

# 10. 10 个大型剧情秘境

## 10.1 落霞古洞府

节点：入口 → 药园 / 石室 → 地宫 / 妖兽巢 → 剑碑 → 石甲地龙。  
核心奖励：无名剑章、筑基材料、古修因果。  
特色：第一个教学型 Roguelite 秘境。

## 10.2 赤炎地宫

节点：熔岩桥 → 火灵群 → 祭坛 / 炼器炉 → 古碑 → 赤炎古灵。  
核心奖励：地脉灵髓、火系法宝、筑基资格。  
特色：路线会改变最终 Boss 环境。

## 10.3 苍梧妖庭遗址

节点：古林 → 灵药园 → 妖族壁画 → 猎妖者营地 → 枯木妖王。  
核心奖励：灵兽、木系功法、妖族声望。

## 10.4 白骨城

节点：城门 → 尸傀街 → 无名墓园 → 将军府 → 白骨将军。  
核心奖励：魂系法宝、阴阳玄髓、历史真相。  
特色：杀怪越多，Boss 魂力越强；超度越多，奖励路线不同。

## 10.5 归墟号古舟

节点：甲板 → 船舱 → 时间错层 → 船长室 → 深海蜃龙。  
核心奖励：古海图、古玉残片、高阶法宝。  
特色：不同年代幻象。

## 10.6 天云剑冢

节点：剑林 → 问剑台 → 历代剑主残影 → 剑心殿 → 天云剑傀。  
核心奖励：无名剑章下卷、剑道传奇词条。

## 10.7 极北界门

节点：冰洞 → 守门人村落 → 封印大厅 → 上古记忆 → 冰魄真君。  
核心奖励：界门钥、守门人功法。

## 10.8 坠魔深渊

节点：魂河 → 禁术室 → 仙蚀实验室 → 魔祖碑 → 噬魂尊者。  
核心奖励：净魂术 / 禁术传承。  
特色：魔念越高，可见隐藏路径越多，但仙蚀风险增加。

## 10.9 虚天核心

节点：太虚档案库 → 守界阵 → 天门派工坊 → 界玦祭坛 → 闻天策。  
核心奖励：太虚盟真相、界玦碎片、阵法传承。

## 10.10 天门核心

节点：飞升台 → 九劫幻境 → 上古断天战场 → 仙门裂隙 → 九劫仙影。  
核心奖励：最终结局。  
特色：此前所有关键变量在此回收。

# 11. 关卡结构

总目标：

```text
约 1000 关
15 张地图
普通地图 50~80 关
重点地图 80~100 关
```

标准节奏：

```text
1~4：普通战斗
5：精英
6~9：普通战斗 + 可能事件
10：小 Boss / 剧情节点
每 20~30 关：大型剧情节点或秘境入口
章节最终：地图 Boss
```

禁止连续 20 关纯粹只提高 HP。

每张地图至少存在：

- 3 种普通怪模板。
- 2 种精英机制。
- 1~2 个章节 Boss。
- 5 个以上地图专属奇遇。
- 1 条主线。
- 2 条以上支线。
- 至少 1 个 Build 相关奖励。

# 12. 自动推关规则

```text
点击战斗
→ 自动战斗
→ 胜利
→ 自动进入下一关
→ 遇剧情则暂停推进
→ 玩家处理剧情 / 选择
→ 继续推关
→ Boss 失败
→ 停留当前关
→ 自动退回最近稳定刷怪点
→ 挂机获取资源
→ 玩家强化 / 改 Build
→ 再次挑战
```

稳定刷怪点：

- 最近已通关且 10 次模拟胜率 ≥ 95% 的普通关卡。
- 服务端可缓存稳定关卡结果，避免频繁模拟。

# 13. 战斗系统

战斗完全自动。

角色自动：

- 普攻。
- 主动法宝。
- 功法触发。
- 装备特效。
- 被动法宝。
- 灵兽技能。

玩家不需要：

- 手动移动。
- 手动瞄准。
- 手动躲避。

玩家负责：

- Build。
- 战前方案。
- 法宝顺序/优先级。
- 元素针对。
- 生存与 DPS 平衡。

基础属性：

```text
HP
ATK
DEF
ASPD
CRIT
CRIT_DMG
HIT
EVA
LIFESTEAL
PEN
DMG_REDUCTION
CDR
金/木/水/火/土伤害
Boss伤害
精英伤害
护盾强度
召唤伤害
DOT伤害
```

初版公式：

```text
基础伤害 = ATK × 技能倍率
减伤率 = DEF / (DEF + DefenseConstant)
实际伤害 = 基础伤害 × (1 - 减伤率)
暴击 = 实际伤害 × CRIT_DMG
```

DefenseConstant 随境界增长。

3. 召唤。
4. 吸血。
5. 反伤。

# 15. 四大 Build

## 15.1 剑修

关键词：飞剑、高频、暴击、穿透、剑阵。

质变机制：

- 飞剑数量。
- 剑意层数。
- 归剑。
- 剑阵。
- 穿透连锁。

典型核心：

```text
剑意达到 10
→ 展开太虚剑阵
→ 飞剑获得穿透
→ 每次暴击减少剑阵法宝冷却
```

## 15.2 法修

关键词：五行、雷火、水冰、AOE、元素反应。

元素联动：

- 水 + 雷：感电跳跃。
- 火 + 木：燃烧扩散。
- 水 + 冰：冻结。
- 土 + 火：熔岩持续伤害。
- 金 + 雷：破甲雷击。

## 15.3 体修

关键词：HP、护盾、反伤、格挡、积势。

核心：

```text
受伤 → 积势
积势满 → 镇岳反击
护盾破裂 → 触发金身
```

## 15.4 魔修

关键词：吸血、DOT、魂、献祭、召唤。

核心：

```text
消耗当前生命
→ 召唤血魂
→ 血魂造成伤害回血
→ 魂死亡叠加“噬魂”
→ 提升持续伤害
```

原则：

高价值 Build 节点必须改变技能逻辑或画面，而不是只加 10% 数值。

# 44. 数值框架

关卡成长：

```text
EnemyHP(n)  = BaseHP  × HP_Growth^n
EnemyATK(n) = BaseATK × ATK_Growth^n
```

但每张地图重新校准。

推荐做法：

- 普通关卡缓慢指数增长。
- 每 10 关 Boss 有额外倍率。
- 每次大境界突破形成明显台阶。
- 不允许单纯依赖指数导致后期完全失控。

战力只做快速估算：

```text
战力 =
攻击价值
+ 生存价值
+ 暴击价值
+ 技能价值
+ 法宝价值
+ 特殊属性价值
```

战力不是实际胜负唯一指标。

# 45. 掉率与保底原则

不锁死最终具体百分比，但必须遵守：

- 前 10 分钟一定看到蓝装。
- 前 30 分钟至少看到一次紫装或等价高反馈掉落。
- 第一个章节 Boss 必定掉有用装备。
- 第一次大型秘境必定给 Build 可感知奖励。
- 长时间无高品质掉落需要软保底。
- 红/彩装必须稀有，但不能稀有到玩家根本看不到系统。

# 46. 扫荡

已通过关卡可扫荡。

扫荡不渲染战斗。

直接模拟：

```text
耗时
收益
掉落
```

高难 Boss 首次禁止扫荡。

剧情节点首次禁止扫荡跳过。

已完成剧情可允许“快速回顾/跳过”。

---

# 47. 失败保护

Boss 失败：

- 自动回稳定关卡挂机。
- UI 明确提示“卡在哪里”。

建议给原因提示：

```text
生存不足
爆发不足
Boss 护甲过高
受到火系克制
控制抗性不足
```

只提示问题，不给唯一答案。

连续多次失败后：
- 解锁可选 Build 建议。
- 不直接自动替玩家换装。

# 54. 最终体验检查

开发每个功能时都必须回答：

### 1. 战斗看起来爽不爽？
法宝、飞剑、雷法、法阵是否真正可见。

### 2. 掉装备有没有期待感？
装备不能只是数字 +2%。

### 3. Build 有没有质变？
四大流派必须改变技能逻辑和画面。

### 4. 剧情是否让人想继续？
玩家有没有“再推十关看看”的理由。

### 5. 选择有没有后果？
不能只换一句台词。

### 6. 修仙感够不够？
突破、宗门、秘境、奇遇、因果是否组成“人生”，而不是菜单集合。

### 7. 页面是否仍然简洁？
系统很多，但不能一次全部塞给新玩家。

# 55. 开发 Agent 执行规则

开发 Agent 必须：

1. 先检查现有项目。
2. 优先增量修改。
3. 不未经需要重构核心架构。
4. 每完成一个功能必须实际运行。
5. Web 游戏必须浏览器验证。
6. 手机竖屏优先验收。
7. 战斗/剧情/秘境必须通过截图或实际运行检查 UI。
8. 剧情、奇遇、NPC、关卡优先配置化。
9. 每次修改后跑相关回归。
10. 不一次性生成 1000 关静态代码。
11. 内容数据与核心引擎分离。
12. 每轮只汇报：
   - 改了什么
   - 验证了什么
   - 还剩什么

推荐已安装 Skills 时优先使用：

```text
game-studio
game-ui-frontend
sprite-pipeline
frontend-design
develop-web-game
game-playtest
imagegen
```
