# 给开发 Agent 的开发 Prompt

请基于现有《凡尘问道》项目和 `凡尘问道_PRD_v2.0.md` 继续开发。

要求：

1. **不要重写项目，不要推翻现有页面和架构，优先增量修改。**
2. 保留现有自动战斗、装备、法宝、5+2 法宝槽、挂机、境界、地图等已有功能。
3. 第一阶段重点实现：
   - 剧情对话 Overlay
   - NPC 立绘与对话
   - 奇遇选择
   - 剧情条件判断
   - 选择结果持久化
   - NPC 状态 / 因果变量
   - 青石村 → 黑风岭 → 云泽坊市前期主线
4. 第二阶段实现第一个完整剧情秘境：`落霞古洞府`，包含路线节点、战斗、奇遇、宝箱、传承、Boss。
5. UI 必须保持国风水墨修仙风格，不要做成普通后台管理页面。
6. React 负责 UI / Overlay / 菜单，PixiJS 继续负责战斗场景和特效。
7. 剧情、奇遇、NPC、选择、秘境尽量配置化，不要大量硬编码。
8. 每完成一个功能都实际在浏览器运行验证，优先检查手机竖屏。
9. 如果已安装 Skills，优先使用：
   - game-studio
   - game-ui-frontend
   - sprite-pipeline
   - frontend-design
   - develop-web-game
   - game-playtest
10. 不要一次性做完整 1000 关，先完成一个真正好玩的前期闭环。

开发顺序：

```text
现有项目检查
→ 保证原功能正常
→ Story/Event 数据结构
→ 剧情 Overlay
→ 奇遇选择
→ 状态持久化
→ 青石村剧情
→ 黑风岭剧情
→ 云泽坊市剧情
→ 落霞古洞府
→ 浏览器试玩
→ 修 UI / 动效 / 节奏
```

每轮开发结束只汇报：

```text
改了什么
验证了什么
还剩什么
```

目标不是“把功能全部堆出来”，而是先做出一个 **战斗爽、剧情连贯、选择有反馈、玩家愿意继续玩的前期版本**。
